# Nexus

> 面向 AI Agent 的**技能编排系统**（Skill Orchestration System）设计

Nexus 在技能注册表之上补一层**控制平面**：把一组技能声明式地编排成可校验、可恢复、可治理的执行图，并支持按任务描述自动路由技能、按节点派发独立子 Agent。

- 技能注册表回答：*这个 Agent 能加载哪些指令？*
- Nexus 回答：*这些技能应该以什么顺序、在什么条件下、携带什么数据、由哪个 Agent、在什么约束下执行？*

## 核心主张

1. **图即上下文契约** —— 节点只见声明的输入，不见编排者的完整历史。
2. **Flow 也是 Skill** —— 编排可递归组合，且无需改动已有技能发现/路由机制。
3. **模型输出是数据** —— 自动路由与模型规划的子图必须过同一套静态校验器。
4. **权限与预算单调不扩张** —— 子节点与子流程只能继承，不能自我提权。
5. **一切决策可记录可重放** —— 路由、审批、预算、重试决策全部入日志。
